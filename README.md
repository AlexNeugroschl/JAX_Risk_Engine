# JAX Risk Engine
### A Basic Risk Engine Built on JAX 

### Objectives
Create a risk engine based off of ORE (Open-Source Risk Engine) using JAX

In particular, we are focusing on batch calculations done overnight by large investement banks.

The engine should use monte carlo simulations to simulate price fluctuation and caluclate risk by computing the NPV cube and VaR.

### Current Objective
Get ORE to work using python
